# Lantern

局域网聊天、文件传输与本地文件管理工具，面向 Windows 10/11 x64。

[下载 Windows 预览版](https://github.com/miziha012/Lantern/releases/tag/v0.2.0) · [查看版本](https://github.com/miziha012/Lantern/releases)

当前为 **v0.2.0 预览版**，尚需两台物理电脑的完整联测。

## 在两台电脑上使用

1. 把发布压缩包复制到两台 Windows 10/11 x64 电脑，各自完整解压。
2. 打开解压目录中的“Lantern.exe”。不要只复制 exe，它需要同目录的运行库。
3. 两台电脑连接同一局域网。若 Windows 防火墙询问访问权限，在你信任的家庭/办公网络中允许“专用网络”。
4. 在侧栏“附近的设备”点击另一台电脑。如未发现，点击“手动连接设备”，填写对方设置中显示的 IP 和端口。
5. 第一次连接，核对证书指纹，并输入对方设置中的六位配对码。
6. 配对成功后，选择设备，输入文字或拖入文件，点击“发送”。

## 文件管理

- “收到的文件”和“发送记录”显示本机传输历史。
- “添加本地目录”只授权本机界面管理该目录，不会向其他电脑开放目录浏览。
- 搜索支持文件名；筛选支持类型、状态、日期、大小；名称列可切换排序。
- 勾选项目、Shift 连选或选择本页；批量发送、复制、移动或移入回收站。
- 同名接收文件自动添加序号。复制/移动出现重名会报错，不覆盖。
- 传输失败或断网后，在发送卡片点击“重试”；保留两端应用数据以便恢复断点。
- 添加的目录不会自动监控文件变化；外部修改后点击“刷新”。

## 截图

- 默认全局快捷键 Alt + Shift + S，或点击窗口右上角“截图”。
- 在一个显示器上拖动框选，点击“复制”或按 Enter；Esc 取消。
- 确认后截图进入 Windows 剪贴板，可在其他应用中 Ctrl + V。
- 在 Lantern 聊天输入框粘贴会出现预览，点击“发送”才传出。
- 设置中可修改快捷键，冲突会提示。跨屏选区、画笔、马赛克不在本版范围。

## 设置与本地数据

默认接收目录为软件所在文件夹下的 `fileManagement`（例如 `D:\Lantern\fileManagement`）。已有自定义目录保持不变，旧文件不会自动搬动。配对后默认自动接收，可在设置关闭。关闭后逐文件确认。
关闭窗口会退出应用；双方必须保持 Lantern 运行才能通信。修改设备名称后重启应用更新附近设备列表中的广播名称。
数据位于当前 Windows 用户的应用数据目录（开发版通常为 %APPDATA%/lantern-lan）。凭据和历史用 Windows 凭据能力加密，不能直接复制数据目录到另一台机器恢复身份。

## 当前验证范围

已完成本机两个独立 HTTPS 实例的传输测试，以及 Windows Electron 界面自动化。测试覆盖配对、文字双向收发、实际文件校验、同名保护、断点恢复、接收确认、目录筛选批选、重命名、截图与粘贴预览。
仍需两台真实电脑联测，尤其是 Windows 10、防火墙、Wi-Fi 网络隔离、大文件和多屏不同缩放配置。此包未购买发布者代码签名证书，Windows 可能显示未知发布者。
文件夹逐文件传输，暂不发送空目录。完整 iPhone 客户端属于二期。

## 开发

安装 Node.js 后在源码目录执行：

```powershell
npm ci
npm start
npm run check
npm test
npm run test:e2e
npm run pack:dir
```

Electron 安装下载若超时，可按自身网络情况配置 Electron 下载镜像。开发依赖已固定在 package-lock.json。
